## ⭐ Featured projects

### Real-life projects

- 🤖 [job-search-automation](https://github.com/CarolMorgado/job-search-automation) ([live demo](https://carolmorgado.github.io/job-search-automation/))
  AI-assisted job search built with ten n8n workflows. They find new roles, filter and score them against a profile, track them in Notion, and prepare a tailored CV and cover letter for each application, with Claude doing the analysis and writing. The demo runs on invented data.
  Practiced: designing rules, testing each stage, documenting a system

- 🏋️ [runner-gym-log](https://github.com/CarolMorgado/runner-gym-log) ([live app](https://carolmorgado.github.io/runner-gym-log/))
  A gym tracker web app built with AI tools. Each exercise links to a YouTube video, it logs the weight I lift, and it gives me a weekly plan that changes every four weeks. It exports each session so I can add it to Strava.
  Practiced: defining requirements, building with AI tools, publishing with GitHub Pages
